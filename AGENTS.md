# Sonado Studio Website

## Purpose

Sonado Studio is a premium, founder-led creative and technology studio website. It should present the studio's work, expertise, process, and founder with enough clarity and polish to build trust and encourage qualified project enquiries.

The core audience is founders and growing businesses investing in distinctive brands, marketing websites, and selected digital products.

## Project goals

- Premium, founder-led creative studio website
- Responsive, accessible, and performance-conscious
- Figma is the visual source of truth
- Relume components may be used as structural starting points

## Architecture

- Framework and routing conventions
- Component and content locations
- Styling and design-token approach
- Image-handling conventions

## Development workflow

- Inspect existing files before editing
- Make focused changes
- Run lint, type-check, tests, and build
- Explain changes to configuration
- Do not add unnecessary dependencies

## Design implementation

- Preserve semantic HTML
- Support reduced motion
- Meet WCAG AA contrast
- Check mobile and desktop layouts
- Do not reproduce default Relume styling when it differs from Figma
